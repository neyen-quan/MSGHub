# MSG Hub

Aplicación Windows de mensajería, tareas y reloj de trabajo.

El código conserva las particiones y preferencias históricas. Los datos del usuario
no forman parte de este repositorio. Ver DATOS.md y BUILD.md.

Actualizar programa → Buscar actualizaciones → Descargar e instalar.
El ZIP local es una alternativa; el paquete completo sirve para instalar o reparar.

La aceptación en la PC del usuario sigue pendiente hasta confirmar reinicio y datos.

Mensajería permite hasta ocho cuentas: las seis originales y dos adicionales.
Usá **+ Agregar cuenta**, elegí WhatsApp o Telegram y un nombre opcional.
Cada cuenta conserva una sesión independiente; clic derecho en la subpestaña permite
cambiar su nombre. Las vistas divididas mantienen el máximo de tres visibles.
Las cuentas nuevas heredan el silencio si el modo Laburo está activo.
